# Подключение OpenAI к Career Quest

Ключ используется сервером для AI-рекомендаций и диалога с помощником. Без него приложение работает с локальным подбором и справкой.

## 1. Создайте новый ключ

Откройте [API keys в OpenAI Platform](https://platform.openai.com/api-keys), выберите свой проект и создайте секретный ключ. Проверьте доступ проекта к API и выбранной модели, баланс и лимиты запросов. Не отправляйте ключ в чат и не добавляйте его в Git.

Если в прежнем `env.example` уже находился настоящий ключ, отзовите его в OpenAI Platform и создайте новый: удаления строки из текущего файла недостаточно, чтобы удалить ключ из истории Git.

## 2. Создайте локальный .env

В PowerShell перейдите в папку Career Quest. Команда ниже создаст файл только при его отсутствии:

```powershell
if (-not (Test-Path -LiteralPath .env)) { Copy-Item -LiteralPath env.example -Destination .env }
notepad .env
```

Заполните три строки и сохраните файл в UTF-8:

```dotenv
ALLOW_EXTERNAL_AI=true
OPENAI_API_KEY=вставьте_новый_секретный_ключ
OPENAI_MODEL=gpt-4o-mini
```

`OPENAI_MODEL` можно заменить на доступную вашему проекту текстовую модель Responses API. Для AI-рекомендаций она также должна поддерживать Structured Outputs. Имя модели — без кавычек и лишних пробелов. `gpt-4o-mini` — сохранённая настройка этого проекта, не требование использовать именно эту модель.

`.env` уже исключён из Git. Файл `env.example` остаётся пустым шаблоном без секретов. Не сохраняйте ключ в `app.py`, браузере или диалоге помощника.

## 3. Перезапустите приложение

Остановите запущенный сервер сочетанием Ctrl+C в его терминале, затем выполните:

```powershell
python run.py
# Если используется Windows Python Launcher:
py -3 run.py
```

Если окружение уже установлено, можно запустить напрямую:

```powershell
.\.venv-career\Scripts\python.exe -m streamlit run app.py
```

Откройте http://localhost:8501 и войдите в кабинет. Простое обновление страницы не перечитывает настройки уже запущенного процесса. Системные переменные окружения с теми же именами имеют приоритет над `.env`.

## 4. Проверьте подключение

В боковой панели появится «AI настроен». Это означает наличие настроек, а не успешную проверку ключа.

- **Диалог:** нажмите «Открыть AI-помощника», подтвердите передачу контекста и сообщений в OpenAI, задайте вопрос «Какие навыки развивать?». У ответа должна быть подпись «AI-помощник · OpenAI».
- **Рекомендации:** в «Мой маршрут → Подобрать с AI» дайте согласие и нажмите «Получить AI-рекомендации». Подпись «AI-подбор · OpenAI» подтверждает успешный ответ.
- **HR:** откройте «Профили и траектории», выберите сотрудника и нажмите «Обсудить профиль с AI». Контекст ограничен выбранным профилем; переписки разных профилей разделены.

Сообщение «Локальная справка · без AI» означает, что ответ получен без модели. При ошибке рядом появляется причина: ключ отклонён, нет доступа к модели, достигнут лимит либо сервис недоступен.

## Частые проблемы

| Сообщение | Что проверить |
| --- | --- |
| Внешний AI отключён | `ALLOW_EXTERNAL_AI=true`, затем перезапуск сервера |
| API-ключ не задан | Имя файла `.env`, а не `.env.txt`; заполненность `OPENAI_API_KEY` |
| OpenAI отклонил ключ | Новый действующий ключ нужного проекта, без пробелов |
| Нет доступа к API или модели | Доступ проекта и корректность `OPENAI_MODEL` |
| Достигнут лимит | Баланс и лимиты API, частоту запросов |
| AI временно недоступен | Интернет, доступ к OpenAI, повторный запрос позже |
| Настройки не изменились | Полный перезапуск сервера и переменные окружения, перекрывающие `.env` |

## Какие данные отправляются

Только после согласия: синтетические навыки, требования грейда, прогресс, доступные шаги выбранного профиля и последние 12 сообщений. Имя и логин автоматически в контекст не включаются; данные, которые вы сами напишете в сообщении, будут отправлены. Не вводите секреты или реальные персональные данные.

Используется Responses API с `store=false`, таймаутом 20 секунд и без автоматических повторов. Диалог ограничен 2000 символами на вопрос; в текущей сессии отображаются последние 24 сообщения. Выход очищает переписку. `store=false` не является обещанием отсутствия всех служебных журналов провайдера.

Официальная документация: [создание ключа и переменная окружения](https://developers.openai.com/api/docs/quickstart), [передача истории диалога](https://developers.openai.com/api/docs/guides/conversation-state).
