# Career Quest

AI-навигация развития сотрудника для хакатона. Интерфейс помогает сотруднику видеть связь между HR-активностью и следующим грейдом, а HR — находить дефицитные компетенции команды.

## Структура

```text
.
├── app.py                 # Streamlit MVP
├── index.html             # Статичная landing-страница
├── Plan.md                # Концепция, требования и roadmap
├── requirement.txt        # Python-зависимости

├── services/              # AI, БД и бизнес-логика в следующих итерациях
└── pages/                 # Дополнительные страницы Streamlit
```

## Запуск

1. Установите Python 3.10+.
2. Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
pip install -r requirement.txt
```

3. Скопируйте `env.example` в `.env` и при необходимости укажите `OPENAI_API_KEY`.
4. Запустите приложение:

```bash
streamlit run app.py
```

Приложение работает в демо-режиме даже без ключа OpenAI и базы данных. В MVP доступны режимы «Кабинет сотрудника» и «Пульс команды», карта навыков, AI-рекомендация, XP, уровни, streak, бейджи и HR-срез.

## Дизайн

Визуальный стиль использует зелёную палитру и принципы финансового digital-продукта: высокий контраст, много воздуха, карточки, спокойные фоны и акцентные CTA. Это стилистическое направление в духе Halyk Bank, без использования закрытых брендовых материалов.
